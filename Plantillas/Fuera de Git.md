# Fuera de Git

> **Aviso para la IA:** Esta plantilla está sin llenar. Lo que va entre corchetes dobles se llena como dice `<Trabajo Agéntico>/Habilidades/Llenar las Plantillas.md`. Cuando no quede ninguno, borra este aviso.

Los archivos de esta lista hacen falta para trabajar en [[El nombre del proyecto. Lo llena la IA al crear este archivo.]], pero git no los trae. En un computador nuevo, después de clonar, hay que copiarlos a mano a su lugar.

Quedan fuera de git por una de tres razones:

- **Las claves:** Nunca entran al repositorio, para que no queden en su historial ni en cada computador o servicio que lo clone.
- **Lo personal:** Como las reglas propias del linter, que no se le imponen a quien use el proyecto, y la carpeta `Archivos/`, con las notas y los documentos del Director.
- **Lo que pesa mucho:** Como un modelo o una herramienta. Cada versión que entra a git se queda para siempre en el historial, aunque después se borre. El repositorio crece con cada una, y el clon, cada descarga y el respaldo en GitHub se vuelven más lentos y pesados.

Cuando se deja fuera de git otro archivo que hace falta para trabajar, se anota aquí.
