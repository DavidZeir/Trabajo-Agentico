# Usar el computador

Esta habilidad solo aplica a Codex. Léela antes de usar computer use, incluso si el control de la interfaz es solo una parte de la tarea.

1. Sigue la documentación y las instrucciones de la herramienta de computer use disponible. Maximiza la ventana principal de cada aplicación que lo permita antes de interactuar con ella.
2. Para seleccionar todo un texto, usa Ctrl derecho + A (`Control_R+a` en `@oai/sky`).
3. Al terminar toda la tarea de control de la interfaz, registra su finalización como indique la herramienta y reinicia cada sesión que hayas usado para liberar la captura que deja el borde amarillo en la pantalla. Si usaste `cua_repl`, ejecuta `cua_repl.js_reset`. Si usaste `node_repl` con `@oai/sky`, ejecuta `node_repl.js_reset`.
